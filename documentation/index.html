1. Welcome to kinetichub

Thank you for choosing the kinetichub Suite. This plugin brings advanced, hardware-accelerated physics (LERP) and layout tools directly into your native WordPress Block Editor, without the performance bloat of third-party libraries like GSAP.

2. Quick Installation

  1. Download the kinetichub.zip file from your purchase confirmation email or account dashboard at getkinetichub.com.
  2. Log into your WordPress Administrator Panel.
  3. Navigate to Plugins > Add New and click Upload Plugin.
  4. Select the downloaded kinetichub.zip file and click Install Now.
  5. Click Activate once installation completes.
  6. You will now see the kinetichub menu in the left sidebar of your dashboard.

3. License Activation (PRO Features)

The free version includes all 12 blocks with core features. To unlock PRO features (advanced physics engines, WebGL effects, and extended controls), you'll need a PRO license.

Activation Steps:

  1. Navigate to kinetichub > License & System in your WordPress dashboard.
  2. Click Enter License Key or Manage Account.
  3. Follow the secure Freemius activation flow to connect your purchase.
  4. Once activated, all PRO features will unlock automatically across all blocks.

Note: License management is securely handled by Freemius. You can manage billing, renewals, and active sites from your account dashboard.

4. Block Architecture

Every block is engineered with Extreme Performance in mind. If you do not see an animation playing inside the Gutenberg editor, this is intentional. Heavy cursor-tracking mathematics are compiled strictly for the frontend to ensure your editing experience remains crash-free and fast.

Included Blocks (12 Total):

  • Kinetic Box: 3D tilt wrapper with magnetic physics. Place native WP blocks inside to apply perspective transforms.
  • Kinetic Typography: Advanced text reveal animations with character-by-character effects. For best results with scramble animations, use plain text without complex inline formatting.
  • Kinetic Magnetic Button: Call-to-action button with cursor-tracking magnetic pull effect.
  • Kinetic Marquee: Infinite-scrolling gallery with hardware-accelerated physics and smart addons.
  • Kinetic Scroll Divider: Animated SVG line dividers that draw themselves based on scroll position.
  • Kinetic Video Modal: Lightbox video player with cinematic entrance animations.
  • Kinetic Hero Mesh: Interactive 3D WebGL liquid mesh background. Requires a background image to render refractive shaders.
  • Kinetic Before/After: Interactive image comparison slider with physics-based dragging.
  • Kinetic Audio Player: Custom styled audio player with waveform display and accessible controls.
  • Kinetic Split Scroll: Dual-column layout where content pins and snaps beautifully as you scroll.
  • Kinetic Cursor Reveal: Custom cursor tracking with interactive media reveal on hover.
  • Kinetic Ambient Aura: Generative background glows and ambient lighting effects.

Each block includes FREE core features and optional PRO enhancements. Check individual block settings in the editor for feature availability.

5. Custom CSS & Variables

If you need to override styles globally, do not hack the plugin files. Use the built-in Custom Code tab in the kinetichub Dashboard. We automatically inject CSS variables for easy theming:

/* Global accent color (used by buttons, borders, highlights) */
:root {
  --kh-accent: #10b981;
  --kh-glass-blur: 20px;
}

/* Override accent for specific block */
.kh-magnetic-button {
  --kh-accent: #ff6b6b;
}

/* Custom animations */
@keyframes customSlide {
  from { transform: translateX(-100%); }
  to { transform: translateX(0); }
}

Note: Changes take effect immediately on the frontend. Clear your browser cache if styles don't update.

6. Troubleshooting

Block doesn't appear in editor:

  • Verify the block is enabled in kinetichub > My Suite dashboard.
  • Clear your browser cache and hard-reload the editor (Ctrl+Shift+R or Cmd+Shift+R).
  • Check WordPress version (requires 6.2+) and PHP version (requires 7.4+).
  • Temporarily disable other plugins to check for conflicts.

WebGL effects not working (Hero Mesh, Ambient Aura):

  • Check kinetichub > License & System for WebGL support status.
  • Try a different browser (Chrome, Firefox, Safari recommended).
  • Update your graphics drivers to the latest version.
  • Some hosting providers disable WebGL - contact your host if needed.

Animations not smooth / laggy performance:

  • Go to kinetichub > Global Settings and change Performance Mode to "Eco Mode".
  • Reduce the number of active blocks on a single page.
  • Disable unused blocks in My Suite to reduce script load.

Theme conflicts / styling issues:

  • Switch to Twenty Twenty-Four theme temporarily to isolate the issue.
  • Check if your theme loads custom normalize.css or reset.css that may conflict.
  • Use the Custom CSS tab to add overrides specific to your theme.

Custom CSS not applying:

  • Verify you saved changes in the Custom Code tab.
  • Clear browser cache and site caching plugins (WP Super Cache, W3 Total Cache, etc.).
  • Check browser console (F12) for CSS syntax errors.
