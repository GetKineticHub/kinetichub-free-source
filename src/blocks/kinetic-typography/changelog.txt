=== Kinetic Typography ===

= 1.0.13 =
* Fixed: full-width Kinetic Typography could overflow or misalign on themes defining root padding when placed outside a padded container; migrated to the same padding-aware full-width technique used by Hero Mesh.
* Fixed: the hover-triggered Plexus background effect could accumulate duplicate window resize listeners on repeated hover.

= 1.0.0 =
* Initial release of the Kinetic Typography block.
* Added animated text rendering using server-side text splitting.
* Added Reveal, Blur In, and Pop In animation styles.
* Added support for character and word-based animation splitting.
* Added scroll-based animation triggering using Intersection Observer.
* Added movement direction controls.
* Added duration, stagger, viewport threshold, and easing controls.
* Added semantic tag selection for headings, paragraphs, div, and span output.
* Added optional reverse animation order.
* Added outline text styling.
* Added responsive typography controls for desktop and mobile font size.
* Added responsive typography controls for desktop and mobile line height.
* Added accessibility support with a screen-reader friendly text fallback.
* Added reduced motion handling for visitors who prefer less animation.
* Added performance optimizations for long text and dynamic content updates.
